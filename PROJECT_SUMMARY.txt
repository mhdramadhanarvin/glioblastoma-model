4. Query with an intelligent local AI model

================================================================================
QUICK START (3 COMMANDS)
================================================================================

1. SETUP (one time):
   bash setup.sh
   source .venv/bin/activate

2. PREPARE DATA:
   cp ~/Downloads/*.pdf pdfs/         # Copy your PDFs
   python3 main.py extract            # Convert to markdown
   python3 main.py index              # Build searchable index

3. START QUERYING:
   ollama serve                       # Terminal 1: Start Ollama
   python3 main.py query              # Terminal 2: Ask questions

See QUICKSTART.md for detailed steps.

CONFIGURATION OPTIONS
================================================================================

Edit config.py to customize:

  MODEL_NAME = "mistral"
  # Options: "llama2", "neural-chat", "orca-mini", etc.

  MODEL_TEMPERATURE = 0.3
  # Lower (0.0) = more precise, Higher (1.0) = more creative

  PDF_CHUNK_SIZE = 1000
  # Larger chunks = more context, fewer queries needed

  RETRIEVAL_K = 5
  # Number of source documents to use per query

TROUBLESHOOTING
================================================================================

Can't import modules?
  → pip install -r requirements.txt

Ollama not connecting?
  → Make sure: ollama serve is running in another terminal

No PDFs found?
  → Copy PDFs to pdfs/ directory first

Vector index not found?
  → Run: python3 main.py index
